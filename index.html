The bet

Institutional memory belongs in the platform, not in a partner's head.

01

Memory that stays

What a partner learns at one PortCo persists as platform memory. People rotate. The track record does not leave with them.

02

Agent-first, not prompt-first

The partner sets autonomy envelopes and approves. The agents read, propose, and act inside those bounds. Nobody is typing prompts all day.

03

Playbooks that transfer

A playbook that worked at one PortCo is matched to the next company with the same bottleneck. The pattern moves; the value compounds.

The workforce

Eight named employees, one firm identity each.

Every agent has a global firm identity and a per-PortCo authorization profile. The Briar authorized at PortCo A is the same Briar at PortCo B, with the same track record and an autonomy envelope set per action.

The strategic anchor

The AI-native rebuild lever.

"The lever no traditional ops partner can pull."

For each PortCo, Ondine models the AI-native target state and the workforce executes the migration. Four quarters, each milestone owned by an agent, a human, or a contractor.

Q1

Current-state assessment

Reads board packs, ERP exports, org charts, and interview transcripts, with lineage back to every source.

Q2

Target-state model

Which functions stay human, which become agent-driven, which workflows compress from days to minutes.

Q3

Sequenced migration plan

Quarter-by-quarter milestones, each owned by an agent, human, or contractor, cross-checked for compatibility.

Q4

Execution and measurement

EBITDA movement is source-linked and claim-tiered as observed, estimated, or controlled. Built for diligence.
